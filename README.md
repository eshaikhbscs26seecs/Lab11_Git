# Storage Estimator - Feature Version

## Author
Ebadullah Shaikh

## Purpose
The purpose of this project is to converts storage size from gigabytes (GB) to megabytes (MB).

## How to Run
1. Make sure Python is installed.
2. Open PowerShell in the project folder.
3. Run the following command:

```powershell
python storage_estimator.py
```

## Example Input and Output

**Input:**
```text
Enter storage size in GB: 10
```

**Output:**
```text
Storage size in GB: 10.0
Storage size in MB: 10240.0
```
